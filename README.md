## What the Skill does

Turns one paper or research material into an editable, template-conformant academic
presentation with per-page evidence mapping:

- `ingest.py` extracts figures, tables and numbers **each with a verbatim quote locator** —
  anything it cannot locate is dropped and recorded, never guessed;
- `plan.py` builds a page plan (one claim per page, ≤5 bullets, speaker notes, real outline
  from the source's own headings, exclusions explained);
- `build_deck.py` builds a real `.pptx` on the supplied template and asserts at OOXML level
  that the master, theme and footer are intact;
- `render.py` exports a real PDF plus per-slide PNGs (and degrades honestly if no renderer
  exists);
- `evidence.py` produces a per-page evidence map, re-verifying every quote against the source;
- `verify_deck.py` runs gates **V01–V19**; `verdict = PASS` requires zero `FAIL` **and** zero
  `UNVERIFIED`;
- `result_contract.py` emits `result.json` filling **every** key the case's own
  `output_contract` declares, tolerating the fact that hidden cases use different key spellings.

One command runs the chain and is partial-safe:

```bash
python skill/scripts/run.py --case /input/case.json --work /app/work --out /app/output
```

## Honesty notes — please read before judging

- **`fixtures/` and `skill/examples/` are SYNTHETIC.** They are self-made development cases,
  labelled `SYNTHETIC / NOT AN OFFICIAL CASE` in every `case.json.note` and `task.md`. Their
  numbers are invented to be internally consistent and **must never be cited as real
  measurements**. They are not the organizer's hidden cases.
- **No official score is claimed anywhere.** Grading for this challenge is human review, on
  hidden cases, against the organizer's own whiteboard. See
  [`skill/references/measured-gain.md`](skill/references/measured-gain.md) for exactly what was
  measured (rework metrics on our own fixture, where **only one of five metrics discriminates**)
  and what was not.
- **A green gate is not a quality certificate.** The gates cover structure, traceability,
  template preservation and export integrity — they do **not** certify that the presentation is
  good science.
- **Novelty is deliberately understated.** See
  [`skill/references/prior-art.md`](skill/references/prior-art.md): the contribution is an
  *audit layer* (verbatim provenance, template invariants, contract-driven emission, a gate that
  can fail), not a new method for generating presentations.
- **Font fidelity is not certified by previews.** The renderer reports `Liberation Serif` as
  missing on the development host and the PDF embeds substituted faces; this is measured and
  reported rather than hidden. See [`skill/references/exports-fonts-colour.md`](skill/references/exports-fonts-colour.md).
- The fixture papers were generated locally (DOCX → PDF) so that figure cropping, caption
  extraction and verbatim number traceability are all genuinely exercised.

## Reproducing

```bash
python skill/scripts/selftest.py  --fixtures fixtures   # end-to-end + 12 injected-defect negatives
python skill/scripts/gain_check.py --fixtures fixtures --case caseA
python skill/scripts/contract_matrix.py --submission skill
```

`selftest.py` exits non-zero if any injected defect is **not** detected — a self-test that only
prints "OK" would be worse than none, because it manufactures confidence.
